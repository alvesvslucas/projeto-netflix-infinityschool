# Interface de entrada inspirada na Netflix

Exercício de interface com HTML e CSS que reproduz elementos visuais de uma tela de entrada: logotipo, formulário, opção “Lembrar de mim” e links de ajuda.

## Tecnologias

- HTML para a estrutura do formulário.
- CSS para cores, posicionamento e estados dos campos.
- Imagens locais e imagem de fundo carregada de um endereço externo.

## Como visualizar

```bash
git clone https://github.com/alvesvslucas/projeto-netflix-infinityschool.git
cd projeto-netflix-infinityschool
```

Abra `index.html` em um navegador. A imagem de fundo depende de conexão com a internet.

## Estrutura

- `index.html`: tela e formulário.
- `Assets/style/style.css`: estilos.
- `Assets/img/`: logotipo e ícone.

## Escopo

Reprodução visual para estudo. O formulário não implementa autenticação, os links de ajuda e assinatura usam `href="#"`, e o texto sobre reCAPTCHA não corresponde a uma integração presente no HTML.

Netflix e sua identidade visual pertencem aos respectivos titulares. Este projeto não é um serviço oficial da marca.
